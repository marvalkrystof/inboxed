A simple rhythm for the email you want to keep, the clutter you want to clear, and everything in between.

01 / CONNECT

Your mail, connected.

Connect your email account over IMAP, using an app password where required.

↗ Your provider. Your account.
02 / CLASSIFY

A place for everything.

Run a local Ollama model to classify messages into your categories and optionally suggest topic tags. Scans save proposals for review.

⌘ AI running on your computer.
03 / REVIEW

You make the call.

Review, edit, approve, or reject suggestions. Apply labels, archive, or move messages to Trash when you’re ready. Automation is an explicit choice.

✓ Review first. Apply when ready.

Local processing

Email content goes to your local Ollama instance for classification and optional tags. Inboxed has no hosted mailbox backend.

A FRESH START, ONE COMMAND AWAY

Meet your new
email routine.

You’ll need Python 3.13+, uv, and a running local Ollama instance with a compatible model. The README covers model setup and configuration.

Read the setup guide →
GET INBOXED
git clone https://github.com/marvalkrystof/inboxed.git
cd inboxed
uv sync --extra tui
uv run inboxed init
uv run inboxed tui

Open the Accounts tab to connect, then scan and review.
